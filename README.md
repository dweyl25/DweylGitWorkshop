# Dweyl Git Workshop

## About the Project
This is my first Git workshop project. I am learning how to use Git to track changes and manage versions of my files.

## Project Files
- `index.html` - The main HTML page.
- `README.md` - Information about the project and instructions.

## Technologies Used
- HTML
- Git
- Visual Studio Code

## What I Learned
- Initialize a Git repository.
- Track changes using `git status` and `git diff`.
- Stage files using `git add`.
- Save changes using `git commit`.
- View commit history using `git log`.
- Undo uncommitted changes using `git restore`.
